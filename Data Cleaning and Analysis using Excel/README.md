# 📊 Data cleaning and analysis in Excel

Project demonstrating cleaning, sorting and analyzing fleet inventory data.

---

# 🎯 Objectives

- Data Cleaning: 
	- Sort out the widths of all columns so that the data is clearly visible in all cells.
	- Use the Filter feature to look for blanks and remove all empty rows from the data.
	- Use either the Conditional Formatting or Remove Duplicates feature to look for and remove any duplicated records from the data.
	- Check for spelling mistakes in the data and fix them.
	- Use the Find and Replace feature to remove all double-spaces from the data.
	- Department names are split over two columns. Use Flash Fill to reduce it to just one column, and then remove any unnecessary columns.
- Data Analysis:
	- Format data as a table
	- Use AutoSum to calculate SUM, AVERAGE, MIN, MAX, COUNT values
	- Create and sort Pivot tables in ascending/descending order to analyze the data
