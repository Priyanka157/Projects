# 📊 Understanding Car Sales through visualizations in Excel

This project analyzes and visualizes car sales and profits for each dealer using Excel.

---

# 🎯 Objectives
- Create Pivot tables
- Visualize Quantity Sold by Dealer ID as a Bar chart
- Visualize Profit by Date and Model as a Line chart
- Visuaize Profit by Year and Dealer ID as a Column chart
- Visualize Sum of Profits for Hudson model cars by Dealer ID as a Line chart
